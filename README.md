# Miikes-blogs
# 博客系统主要用于记录博客主本人学习、开发过程

## 项目目录

- `src/`：博客源码、页面、组件、样式和文章内容
- `public/`：静态公开资源，例如 favicon
- `docs/blog/`：本博客的开发和维护说明
- `docs/upstream/`：Fuwari 原主题参考文档和示例文章
- `docs/assets/`：仓库说明或文档用图片素材
- `scripts/`：辅助脚本

## 一、使用对象

- **普通用户**：浏览文章、评论、搜索
- **管理员**：发布文章、管理分类 / 标签 / 评论

## 二、面向对象设计（OOP）

- User（用户）
- Article（文章）
- Category（分类）
- Tag（标签）
- Comment（评论）

## 三、主要功能

- 文章展示、详情、搜索
- 分类、标签筛选
- 用户登录注册、评论
- 后台文章 / 分类 / 标签 / 评论管理
